## Critical Directives
- **Product Model**: Evidence & audit system with deterministic color analysis, NOT an AI-first gimmick.
- **Result Labels**: Must always use `PRESUMPTIVE_POSITIVE`, `PRESUMPTIVE_NEGATIVE`, `INCONCLUSIVE`.
- **Disclaimer**: Every result screen must display *"PRESUMPTIVE FIELD RESULT: This record does not constitute laboratory confirmation."*
- **Integrity Terminology**: Always say "tamper-evident", NEVER "tamper-proof".
- **Design Aesthetic**: Institutional, government field tool. Deep navy (`#172033`), slate borders (`#E2E8F0`), crisp white (`#FFFFFF`). Never neon or glassmorphism.
- **Crypto Rules**: Never invent custom crypto. Use Web Crypto API or audited libraries. Server-side Ed25519 signing.
